# CLAUDE.md

Project harness for **Owlet** — a SwiftUI macOS menu-bar app (`Owlet/`) plus a Rust CLI rewriter (`tools/rewriter/`) that drives a local Ollama model. See `README.md` for the product overview.

## Startup Workflow

Before writing code:

1. `pwd` — confirm you're in `~/Repos/owlet`
2. Read this file
3. Read `feature_list.json` and `progress.md`
4. Skim `README.md` for prereqs and the manual smoke-test checklist
5. Check `git log --oneline -8` and `git status`
6. If touching design work, browse `docs/superpowers/specs/` and `docs/superpowers/plans/` for the relevant initiative
7. Only run `./init.sh` when you actually need the verification suite — it builds the Rust binary AND the macOS app (slow); for small edits, run just the affected check

If baseline verification is failing, fix that before adding new scope.

## Working Rules

- **One feature at a time.** Pick exactly one unfinished entry from `feature_list.json`. Don't pile on unrelated changes.
- **Spec → plan → ship.** Non-trivial work lives in `docs/superpowers/specs/YYYY-MM-DD-<topic>-design.md` and `docs/superpowers/plans/YYYY-MM-DD-<topic>.md`. Reuse that workflow for anything bigger than a one-file change.
- **Evidence before "done".** Run the verification command for the layer you touched (see below) and paste a result line into `feature_list.json` evidence.
- **Stay in scope.** Don't refactor adjacent code or update unrelated dependencies.
- **Leave the repo restartable.** `./init.sh` should pass from a clean checkout when you stop.

## Verification Commands

`./init.sh` runs everything. For tighter loops, pick the layer you touched:

```bash
# Rust rewriter (fast — seconds)
(cd tools/rewriter && cargo test)

# Rust + Ollama smoke (requires `ollama serve` + qwen2.5:1.5b pulled)
(cd tools/rewriter && cargo build --release && bash tests/smoke.sh)

# Swift app build only
(cd Owlet && xcodegen generate && \
  xcodebuild -project Owlet.xcodeproj -scheme Owlet \
    -configuration Debug -destination 'platform=macOS' build)

# Swift XCTest target
(cd Owlet && xcodebuild test -project Owlet.xcodeproj \
  -scheme Owlet -destination 'platform=macOS')

# Full re-install (signs + copies to ~/Applications, opens System Settings)
./install.sh
```

After app behavior changes, also walk the **Manual smoke test checklist** in `README.md`.

## Project Layout (quick map)

- `Owlet/` — SwiftUI macOS app. Generated by xcodegen from `Owlet/project.yml`. Sources in `Owlet/Owlet/`, tests in `Owlet/OwletTests/`. Asset catalog at `Owlet/Owlet/Assets.xcassets/`.
- `tools/rewriter/` — Rust CLI (`owlet-rewriter`). stdin → Ollama → stdout. Smoke test in `tests/smoke.sh`.
- `install.sh` — Idempotent installer (Ollama pull, cargo build, xcodebuild, ad-hoc sign, install to `~/Applications`, strip quarantine).
- `docs/superpowers/specs/` and `docs/superpowers/plans/` — design + execution docs.
- `.remember/` — append-only session memory (`now.md`, `today-*.md`, `recent.md`, `archive.md`). Treat as read-mostly across sessions.

## Definition of Done

A feature is done only when:

- [ ] Target behavior is implemented
- [ ] Layer-specific verification command ran clean
- [ ] App-facing change → manual smoke test step from README walked
- [ ] Evidence pasted into `feature_list.json` `evidence` field
- [ ] `progress.md` updated; `git status` clean or intentionally staged
- [ ] `./init.sh` still passes from a clean checkout

## End of Session

1. Update `progress.md` (what shipped, what's next, blockers)
2. Update `feature_list.json` status + evidence
3. If multi-session, fill `session-handoff.md`
4. Commit with a descriptive message (or leave a clean working tree and note it)

## Escalation

- **Architecture / behavior decisions** → check `docs/superpowers/specs/` first, then ask the user
- **TCC permission flakiness** (Accessibility / Input Monitoring) → see README Troubleshooting; ad-hoc re-signs invalidate grants
- **Ollama not responding** → `ollama serve` in another terminal; `qwen2.5:1.5b` must be pulled
- **Repeated test failures** → flag in `progress.md`, stop and ask
